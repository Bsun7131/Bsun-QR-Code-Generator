## 🔐 Privacy

Bsun QR Code Generator is designed to generate QR codes locally within your web browser.

* No account or registration is required.
* Text, URLs, email addresses and phone numbers entered into the generator are processed locally in your browser.
* The application does not send QR code content to an external QR-generation service.
* Generated QR codes can be downloaded directly to your device.
* The application does not intentionally collect or store users' personal information.

**Please note:** The website is hosted on GitHub Pages. The hosting provider may process technical information, such as IP addresses and access logs, as part of delivering the website.
